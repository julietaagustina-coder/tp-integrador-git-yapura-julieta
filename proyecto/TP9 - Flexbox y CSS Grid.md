## Trabajo Práctico 9: Flexbox y CSS Grid

**Objetivo:** Mejorar la estructura y adaptabilidad del sitio web de la agencia de viajes mediante la aplicación estratégica de Flexbox y CSS Grid, y desarrollar criterio de diseño responsive.

---

### 1. Análisis Previo
- **Identificar componentes** óptimos para Flexbox (menú, tarjetas, formularios, testimonios, footer, contacto).  
- **Detectar secciones** adecuadas para CSS Grid (layout principal, galerías, comparadores, detalle de destinos, calendarios).  
- **Problemas de diseño** actuales a resolver (alineación, espaciado, proporciones).

### 2. Implementación de Flexbox
- Aplica Flexbox en **3+ componentes** (e.g., menú de navegación, tarjetas de paquetes, footer).  
- Usa las propiedades: `display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `gap`, `flex`.

### 3. Implementación de CSS Grid
- Aplica Grid en **2+ secciones o páginas completas** (página principal, galerías de imágenes).  
- Aplica: `display: grid`, `grid-template-columns/rows`, `grid-template-areas`, `gap`, `grid-column/row`, funciones `repeat()`, `minmax()`.

### 4. Diseño Responsive
- Garantiza adaptabilidad en **móvil, tablet y escritorio**.  
- Emplea **media queries** para reorganizar elementos según puntos de quiebre.

### 5. Mejoras Adicionales
- Efectos `:hover` y **transiciones suaves**.  
- Consistencia en **jerarquía visual**, espaciados y proporciones.  
- Corrección de **alineaciones** previas.

---

### Buenas Prácticas
- **Código limpio:** comentarios claros, nomenclatura consistente, DRY ("Don’t Repeat Yourself").  
- **Organización lógica** del CSS por bloques y componentes.

*Entrega:* Archivo con los fragmentos de CSS y capturas del diseño implementado.
